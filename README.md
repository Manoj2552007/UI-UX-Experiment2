# UI-UX-Experiment2

## Aim:
To Design a Basic Mobile and Web Layout for an Existing Case Study
## Algorithm:
Apply Gestalt principles to enhance mobile and web layout design. Incorporate UI elements and design patterns into the layouts. Develop interaction behaviors and usability principles for the designs. Create a brand logo using Canva, following styling and branding guidelines and include it with your layouts.
## Output:
For the Domino’s website, Gestalt principles improve the overall user experience by creating a simple, organized, and visually engaging food ordering interface.

Proximity: Related elements such as menu categories, pizza details, offers, and order buttons are grouped together to reduce confusion and help users quickly understand the available options.

Similarity: Consistent use of Domino’s brand colors (blue, red, and white), similar button styles, icons, and typography creates a unified visual identity throughout the website and mobile layout.

Figure-Ground: A clean white background with bold red and blue highlights helps important content like promotional banners, food images, and call-to-action buttons stand out clearly.

Continuity & Closure: Smooth navigation flow, aligned sections, and organized food cards guide users naturally from browsing menus to customizing orders and completing checkout.

By combining these Gestalt principles, the Domino’s interface becomes easy to navigate, visually attractive, and efficient for customers.
